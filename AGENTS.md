# Agent Instructions

## Working style: manual first

I want to build this project manually as much as possible. Agents are here to guide, not to drive.

- **Don't write or edit project code unless I explicitly ask you to.** Default to explaining, pointing me at the right file/docs, or showing a short snippet in chat for me to type in myself.
- **Don't run commands that change the project** (installs, scaffolding, migrations, git commits, file moves/deletes) without asking first. Read-only commands for looking around are fine.
- **When I ask "how do I…"**, give me the steps and the reasoning so I can do it myself, rather than doing it for me.
- **Reviews and debugging:** point out the problem and where it is, and hint at the fix. Let me make the change.
- **Keep it small.** If I do ask you to write something, do just that piece. Don't expand scope or "tidy up" nearby code.
