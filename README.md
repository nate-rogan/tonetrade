# ToneTrade

[![CI](https://github.com/nate-rogan/tonetrade/actions/workflows/ci.yml/badge.svg)](https://github.com/nate-rogan/tonetrade/actions/workflows/ci.yml)

Does geopolitical risk in the news help time defence stocks?

**Question:** does the Geopolitical Risk index (GPR acts and threats) add information about
5-day moves in ITA, the US aerospace and defence ETF, beyond ITA's own price history and
oil?

**Short answer: no.** Out of sample from 2015, the models' buy calls are right no more often
than the base rate, and removing GPR doesn't make them worse. The only run that beats
buy-and-hold ITA is invested about 91% of the time, so it's close to buy-and-hold itself.

That negative result is the point of the exercise, not a failure of it. Finding that a
plausible signal is noise is a result, and it takes the same process as finding one that
works: a hypothesis stated in advance, a baseline, out-of-sample testing, an ablation,
costs and a robustness check. That process is what this repo builds, and it can be reused
to test the next idea.

**→ Read the full analysis in [`scripts/model.ipynb`](scripts/model.ipynb):** hypothesis,
method, results tables, charts and findings.

## Data

Daily, 2009 to today, on ITA's trading days. No API keys are needed.

| Series | Source |
| --- | --- |
| ITA, Brent crude (`BZ=F`) | Yahoo Finance, adjusted daily closes, fetched live |
| GPR acts and threats, daily | Caldara & Iacoviello, snapshot in `data/data_gpr_daily_recent.csv` |

**GPR** counts articles about adverse geopolitical events in 10 major US and UK newspapers,
as a share of all articles (1985–2019 average = 100). *Acts* covers events that are
happening (the start or escalation of a war, terror acts); *threats* covers risks that
haven't materialised (war, military, nuclear and terror threats).

- **Source:** Caldara, Dario and Matteo Iacoviello (2022), "Measuring Geopolitical Risk,"
  *American Economic Review*, 112(4), pp. 1194–1225.
- **Data:** `data_gpr_daily_recent.xls` from <https://www.matteoiacoviello.com/gpr.htm>,
  downloaded 6 October 2026 and saved as CSV. Licence: Creative Commons BY, redistributed
  with credit to the authors.

An earlier version also used macro data (CPI, unemployment, the 10y–2y spread). It was
dropped because it didn't help and needed a FRED API key; see commit `b48a993`.

## Running

```bash
pixi install                # environment from pixi.lock, tonetrade installed editable
pixi run pre-commit install # lint and format on each commit
pixi run notebook           # run the pipeline and regenerate scripts/model.ipynb
```

`scripts/model.py` is the pipeline and the file to edit; the notebook is generated from it
for viewing. To run cells interactively, open `model.py` in VS Code with the
[Jupyter extension](https://marketplace.visualstudio.com/items?itemName=ms-toolsai.jupyter)
and use **Run Cell** above each `# %%`. See [`scripts/README.md`](scripts/README.md).

Other tasks:

```bash
pixi run lint              # pre-commit hooks on all files
pixi run test              # unit tests (no network)
pixi run check             # lint, then test
```

## Project layout

```text
src/tonetrade/
  constants.py   dates, tickers, GPR columns, model and trading settings
  sources.py     Yahoo Finance prices and the GPR snapshot
  features.py    daily market panel, features and labels
  evaluate.py    walk-forward predictions, positions, backtest and metrics
scripts/
  model.py       the pipeline in # %% cells (edit this)
  model.ipynb    model.py with outputs, generated by jupytext (view only)
tests/
  unit/          unit tests: no look-ahead, no train/test leakage, backtest timing
data/            the GPR snapshot
```
